Label formats

Save & apply

Your changes take effect when you click Save & apply. Windows then knows the formats as paper sizes, and every program offers them.

  1. Save & apply

    While something isn't applied yet, the window title has an asterisk: "QL Label Formats *". Click Save & apply at the top right.

    Windows asks once for administrator permission, because paper sizes apply to all users of the PC. Then the status bar says "Applied" with the time, and "Windows paper sizes in sync".

    If you answer No, nothing changes and your changes stay in the window. A bar at the top says so; Apply again asks once more.

    Keys
    Ctrl + SSave & apply

  2. Revert

    File > Revert brings back the list as last applied; all changes since then are lost. If you close the window with changes not applied, it asks first.

  3. Choose it in a program

    In Word and other programs, choose the QL printer and then the paper size with your label format's name, for example in the page setup or the printer properties.

    QL Label Maker shows your formats at the top of its Label list, before Brother's papers.

Test print and default before applying

A format Windows doesn't know yet can't be test-printed or set as default. The program then offers to apply first.

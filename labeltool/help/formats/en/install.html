Printers

Installing, repairing, uninstalling

The driver and the programs come in a zip with Setup.exe. The driver is signed on your PC with a certificate of its own; you never have to trust someone else's certificate.

  1. Installing

    Extract the whole zip (right-click > Extract All), connect and switch on the printer, then double-click Setup.exe. If Windows says "Windows protected your PC": More info > Run anyway.

    The window takes you through four steps:

    1. Check this PC: the kind of PC (x64 or ARM64), the installed and the new version, connected QL printers and their roll.
    2. Sign the driver for this PC.
    3. Install the driver and the programs: one administrator prompt. Before it you choose whether to be notified about printer errors.
    4. Print a test label on the loaded roll.

    Afterwards the Start menu has QL Label Formats, QL Label Maker and QL Printer Status.

  2. ARM64 PCs: restart with key 7

    Windows on ARM64 installs a self-signed driver only after a restart with driver signature enforcement off once. The window has a step of its own for it:

    1. Prepare and restart (one administrator prompt).
    2. On the blue Startup Settings screen, press 7.
    3. After you sign in, the window opens again. When Windows asks about the publisher, choose Install this driver software anyway.
    4. Finally, restart normally. The driver then keeps working with enforcement on.

  3. Repairing or updating

    Start Setup.exe from the extracted zip again. It checks the PC and installs the driver and the programs anew; printers, settings and label formats stay. Printer setup has a link to the download page at the bottom.

  4. Uninstalling

    In Windows Installed apps > QL Unidrv printer driver > Uninstall, or Uninstall in Printer setup. The window first shows what will be removed: the QL printers, the programs, the driver, its certificate and the logs.

    Keep my label formats is ticked: the list then stays for a later install. A shared printer is marked orange, because other PCs can't print through it any more.

When Windows blocks the driver

If Smart App Control or Windows protected print mode is on, the check in the first step says so right away: they allow only programs with a paid signature, or only Windows' own printer drivers.

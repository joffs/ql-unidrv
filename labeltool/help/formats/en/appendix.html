Keys and programs

  • Keys

    KeysCommand
    Ctrl + NNew
    Ctrl + SSave & apply
    DelDelete (in the list)
    Alt + ↑ / ↓Move up / Move down (in the list)
    F5Test print
    F6Printer status
    F1This help, at the page for the open window (also in Printer setup and Printer status)
    Help > About QL Unidrvprogram and driver versions; Copy copies them for a support request

  • The programs in the Start menu

    QL Label Formats
    label formats, test print, printer setup (this program, QlLabelFormats.exe).
    QL Label Maker
    design and print labels (QlLabelMaker.exe); also through Label Maker in the toolbar.
    QL Printer Status
    the status window of all QL printers (QlPrinterStatus.exe).

    All three are in C:\Program Files\QLUnidrv.

  • Language

    The programs follow Windows' display language: German on a German Windows, English otherwise. Tools > Language / Sprache changes it.

  • Appearance

    The programs are light or dark like Windows (Settings > Personalisation > Colours). Tools > Appearance picks Light or Dark for all QL programs; Like Windows follows Windows again. The choice applies at once, also to windows already open. With High Contrast on, Windows sets the colours.

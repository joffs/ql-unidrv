  • Kommandozeile

    Der QL Label Maker ist QlLabelMaker.exe in C:\Program Files\QLUnidrv. Er nimmt eine Etikettendatei und zwei Angaben:

    QlLabelMaker.exe [Datei.qllabel] [--printer "Druckername"] [--format "Etikettenformat"]
    Datei.qllabel
    öffnet dieses Etikett
    --printer
    wählt den Drucker, so wie er in Windows heißt
    --format
    wählt das Etikettenformat

    Beispiel:

    "C:\Program Files\QLUnidrv\QlLabelMaker.exe" --printer "Brother QL-800 (Unidrv)" --format "62mm"

    QlLabelFormats.exe --editor mit denselben Angaben startet ihn ebenfalls.

  • Darstellung

    Die Programme sind hell oder dunkel wie Windows (Einstellungen > Personalisierung > Farben). Extras > Darstellung wählt Hell oder Dunkel für alle QL-Programme; Wie Windows folgt wieder Windows. Die Wahl wirkt sofort, auch in schon offenen Fenstern. Bei hohem Kontrast bestimmt Windows die Farben, dann ist der Menüpunkt grau. Das Etikett selbst bleibt immer weiß mit schwarzem Druck, so wie es aus dem Drucker kommt.

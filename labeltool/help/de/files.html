Drucken und Dateien

Speichern und Öffnen

Ein Etikett ist eine .qllabel-Datei. Alles steckt darin, auch die Bilder; Sie können sie kopieren, verschicken und auf einem anderen PC öffnen.

  • Speichern

    Datei > Speichern speichert das Etikett, beim ersten Mal an einem Ort Ihrer Wahl; Datei > Speichern unter... legt eine Kopie unter neuem Namen an.

    In der Datei stehen das Etikettenformat (Name, Papier und Länge), die Richtung und alle Objekte. Bilder werden eingebettet; die Bilddatei wird danach nicht mehr gebraucht. Drucker und Auflösung gehören nicht zur Datei.

    Ungespeicherte Änderungen zeigt ein Sternchen im Fenstertitel, zum Beispiel Regal 3 *. Vor Neu, Öffnen und beim Schließen fragt der QL Label Maker: Änderungen an diesem Etikett speichern?

    Tasten
    Strg + Sspeichern
    Strg + Umschalt + Sspeichern unter

  • Öffnen und neu anfangen

    Datei > Öffnen... oder ein Doppelklick auf die Datei im Explorer. Datei > Neu beginnt ein leeres Etikett auf dem gewählten Etikettenformat. Starten mit einer Datei, einem Drucker oder einem Format: Kommandozeile.

    Tasten
    Strg + Oöffnen
    Strg + Nneu

  • Auf einem anderen PC oder Drucker

    Gibt es das Etikettenformat dort nicht, nimmt der QL Label Maker ein Format oder Papier mit demselben Papier und derselben Länge und sagt das beim Öffnen: Das Etikett wurde für „…“ gestaltet, das … nicht anbietet. Es wird auf … angezeigt. Gespeichert wird es dann weiter für das ursprüngliche Format.

    Ein Etikett mit eigener Länge öffnet auf demselben Band, wenn der Drucker es hat.

    Dateien aus einer neueren Version des QL Label Maker öffnen ebenfalls. Objekte, die diese Version noch nicht kennt, werden weggelassen, und eine Meldung sagt, wie viele.

Etikettenformate gehören nicht zur Datei

Die Datei nennt nur den Namen des Formats. Die Formate selbst verwaltet QL Label Formats, für alle Programme gemeinsam: Etikettenformate und eigene Längen.

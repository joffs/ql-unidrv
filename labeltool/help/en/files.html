Printing and files

Saving and opening

A label is a .qllabel file. Everything is in it, pictures too; you can copy it, send it and open it on another PC.

  • Saving

    File > Save saves the label, the first time wherever you choose; File > Save as... makes a copy under a new name.

    The file holds the label format (name, paper and length), the direction and all objects. Pictures are embedded; the picture file isn't needed afterwards. The printer and the resolution are not part of the file.

    An asterisk in the tab and the window title shows unsaved changes, for example Regal 3 *. File > Close label, the tab's ✕ or the middle mouse button close the label and ask first: Save the changes to “Regal 3”? Closing the window (File > Exit) asks once for all unsaved labels, with a list to tick.

    Keys
    Ctrl + Ssave
    Ctrl + Shift + Ssave as
    Ctrl + Wclose label

  • Opening and starting anew

    File > Open... or double-click the file in Explorer. File > New or the + at the end of the tabs starts an empty label ("Untitled 1") on the active tab's printer and label format. Starting with a file, a printer or a format: command line.

    Each label has its own tab above the label, with its own printer, format, zoom and undo. Ctrl + Tab goes to the next one. QL Label Maker has one window: a label file you open while it is running opens there in a new tab. If it is already open, its tab comes forward and blinks briefly.

    File > Recent labels shows the last 15 labels, the newest at the top, with their folder beside them; the digits 1 to 9 open them directly. A label joins the list when you open or save it. The ✕ on an entry or Del takes it off the list, Clear list... empties it; the files themselves stay. A missing file shows grey with "not found". A network folder is checked only when you click; if it can't be reached, you can try again.

    Keys
    Ctrl + Oopen
    Ctrl + Nnew
    Ctrl + Tabnext tab

  • On another PC or printer

    If the label format doesn't exist there, QL Label Maker takes a format or paper with the same paper and length and says so when it opens: The label was made for '…', which … doesn't offer. It is shown on …. It is still saved for the original format.

    A label with a length of its own opens on the same tape if the printer has it.

    Files from a newer version of QL Label Maker open too. Objects this version doesn't know yet aren't shown, and a message says how many; they stay in the file when you save. Some parts may look simplified; a message says so too.

Label formats are not part of the file

The file only names the format. QL Label Formats manages the formats themselves, shared by all programs: Label formats and custom lengths.

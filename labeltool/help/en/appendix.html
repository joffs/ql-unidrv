  • Command line

    QL Label Maker is QlLabelMaker.exe in C:\Program Files\QLUnidrv. It takes a label file and two options:

    QlLabelMaker.exe [file.qllabel] [--printer "printer name"] [--format "label format"]
    file.qllabel
    opens this label
    --printer
    chooses the printer, by its name in Windows
    --format
    chooses the label format

    Example:

    "C:\Program Files\QLUnidrv\QlLabelMaker.exe" --printer "Brother QL-800 (Unidrv)" --format "62mm"

    QlLabelFormats.exe --editor with the same options starts it too.

  • Appearance

    The programs are light or dark like Windows (Settings > Personalisation > Colours). Tools > Appearance picks Light or Dark for all QL programs; Like Windows follows Windows again. The choice applies at once, also to windows already open. With High Contrast on, Windows sets the colours and the menu entry is greyed. The label itself always stays white with black print, as it comes out of the printer.
